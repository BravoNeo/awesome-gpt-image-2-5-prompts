## About GPT Image 2.5

GPT Image 2.5 is OpenAI’s image generation and editing family. [Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) emphasizes precise editing, while [Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare) is designed for fast everyday image generation. Both take text and image inputs. The collection uses the model names supplied by creators.
